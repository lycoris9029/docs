The **Library Reservation System** backend is a Java/Spring Boot multi-module application for room and seat management, reservations, face-verified attendance, violation reporting, and administrative operations.

This guide extends the existing Mintlify documentation with implementation-level detail. **It extends the existing site with implementation-level engineering documentation**, and it does not claim production verification.

## How to read this documentation

- **Implementation notes** describe behavior present in the supplied backend archive.
- **Recommendations** describe improvements that are not yet implemented.
- **Example API calls** illustrate controller contracts; they were not executed against a running instance.
- Source links lead to the Java project repository; the source-grounded **Backend API Contract** is available under the **API Reference** tab.

<Warning>
  The inspected repository includes sensitive configuration. Rotate any exposed credentials and remove them from source history before publishing code or configuration files publicly. This guide contains no secret values.
</Warning>
