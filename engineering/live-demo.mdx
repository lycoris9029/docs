# Overview

This page demonstrates how we can **manage documentation just like source code**.
By editing an MDX file, committing the changes, and pushing them to GitHub, we can keep our documentation up to date.

## How to update this page

1. Open `engineering/live-demo.mdx` in your code editor.
2. Make a small change to the table above.
3. Commit the update with Git.
4. Push your commit to GitHub.
5. Refresh the documentation website to see the published change.

## Why manage documentation with Git?

- **Version history:** Track what changed and when.
- **Collaboration:** Review changes before merging them.
- **Consistency:** Keep documentation aligned with project updates.

## Live demo challenge

Change the **Documentation version** from `1.0` to `1.1` and the **Release status** from `Draft` to `Published`. Then push your changes to GitHub.

> **Tip:** Small documentation updates follow the same Git workflow as source code updates.
